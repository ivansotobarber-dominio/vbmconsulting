# VB&M Web

Web matriz de VBM con foco principal en VB&M Ingenieria, ingenieria de caminos, proyectos, informes, peritajes y asistencia de obra.

## Estado

Primera identidad publica y prototipo editorial. La denominacion legal, dominio, correo, telefono, portfolio y datos societarios deben confirmarse antes de publicar como web comercial definitiva.

## SEO y GEO incorporados

- HTML semantico, respuestas directas y URLs descriptivas.
- Metadatos, robots, sitemap y datos estructurados Organization/ProfessionalService.
- Area de servicio Canarias, especialidades y verticales expresadas de forma legible.
- Contenido pensado para que buscadores y asistentes identifiquen quien es VBM, que hace, para quien y en que territorio.
- No se han inventado clientes, obras, certificaciones, direcciones, precios ni testimonios.

## Pendientes de lanzamiento

1. Confirmar denominacion legal frente a la marca publica.
2. Elegir dominio y sustituir `__SITE_URL__`.
3. Configurar correo profesional y formulario real.
4. Incorporar casos de uso reales con autorizacion.
5. Crear paginas SEO por servicio y sector.
6. Conectar Search Console, analitica y ficha de empresa si existe ubicacion publica.
